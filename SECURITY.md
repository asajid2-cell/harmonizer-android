# Security Policy

## Reporting a Vulnerability

Report security issues to **welterpop@harmonizerlabs.cc**.

Do not open a public GitHub issue for security vulnerabilities.

## Scope

- The Android app itself (this repo)
- API calls to `harmonizerlabs.cc`

Out of scope: the VPS backend (separate codebase), third-party dependencies.

## Response

Expect an acknowledgement within 72 hours. Fixes are prioritised based on severity.
